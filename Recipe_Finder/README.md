## Recipe Finder

A responsive web application that helps users discover recipes from around the world. Search for meals, explore ingredients, read cooking instructions, and access recipe videos.

## Features

- Search for recipes by meal name or keyword
- Display recipe images and categories
- View detailed cooking instructions
- Show ingredients and their measurements
- Open recipe videos on YouTube when available
- Handle empty searches and API errors
- Responsive interface with a clean design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- [TheMealDB API](https://www.themealdb.com/api.php)
- Font Awesome icons
