# Bookmark Saver

A simple bookmark management web application that allows users to save, view, and remove their favorite website links. The application uses the browser's **Local Storage** to persist bookmarks, ensuring they remain available even after the page is refreshed.

## Features

- Add bookmarks with a custom name and URL
- Validate empty input fields
- Validate URLs to ensure they begin with `http://` or `https://`
- Open saved bookmarks in a new browser tab
- Remove unwanted bookmarks
- Store bookmarks using Local Storage
- Automatically load saved bookmarks when the page opens
- Responsive user interface
- Vintage-inspired dark design

## Technologies Used

- **HTML5** – Structure of the application
- **CSS3** – Styling, layout, animations, and responsive design
- **JavaScript** – Application functionality and DOM manipulation
- **Local Storage API** – Persistent bookmark storage
