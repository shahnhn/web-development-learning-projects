# Registration Form

A simple and responsive registration form built using **HTML, CSS, and JavaScript**. This project focuses on client-side form validation and provides visual feedback when users enter valid or invalid information.

## Features

* Username validation
* Email format validation
* Password length validation
* Confirm password validation
* Required field validation
* Success and error feedback
* Form reset after successful registration
* Responsive and user-friendly design

## Technologies Used

* **HTML5** – Structure of the registration form
* **CSS3** – Styling and visual feedback
* **JavaScript** – Form validation and interactivity

## Validation Rules

The form checks the following:

| Field            | Validation                          |
| ---------------- | ----------------------------------- |
| Username         | Must be between 3 and 15 characters |
| Email            | Must be a valid email address       |
| Password         | Must be between 6 and 25 characters |
| Confirm Password | Must match the password             |
| All Fields       | Cannot be empty                     |
