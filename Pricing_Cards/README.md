## Pricing Cards

A responsive pricing cards UI built with HTML and CSS. This project presents three subscription plans with a polished SaaS-style design, responsive layouts, hover interactions, feature indicators, and a highlighted "Most Popular" plan.

## Features

* Three responsive pricing plans:

  * Basic
  * Pro
  * Enterprise
* Highlighted "Most Popular" Pro plan
* Responsive three-column desktop layout
* Tablet and mobile responsive layouts
* Hover animations and transitions
* Animated card entrance effects
* Feature availability indicators
* Pricing hierarchy with monthly billing
* Font Awesome icons
* Testimonial section
* Accessible focus states
* Reduced-motion support
* High-contrast preference support
* CSS custom properties for consistent theming

## Technologies Used

* HTML5
* CSS3
