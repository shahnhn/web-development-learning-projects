## Contact Form

A modern and responsive contact form interface built with **HTML and CSS**. The project features a dark cybersecurity-inspired design with neon-violet accents, responsive layouts, interactive form fields, and contact information.

## Features

* Name input
* Email input
* Telephone input
* Subject input
* Message textarea
* Required-field validation using HTML
* Responsive two-column layout on larger screens
* Single-column layout on mobile devices
* Interactive focus states
* Hover animations
* Neon-violet visual theme
* Contact information section
* Font Awesome icons
* Reduced-motion accessibility support
* High-contrast preference support

## Technologies Used

* **HTML5** – Page structure and form elements
* **CSS3** – Styling, responsive design, animations, and visual effects
* **Font Awesome** – Interface icons

## Design

The form uses a cybersecurity-inspired visual style featuring:

* Dark background
* Neon-violet accents
* Glassmorphism effects
* Subtle grid texture
* Glowing focus states
* Animated interactions
* Responsive design

## Form Fields

| Field   | Type      | Required |
| ------- | --------- | -------- |
| Name    | Text      | Yes      |
| Email   | Email     | Yes      |
| Phone   | Telephone | No       |
| Subject | Text      | Yes      |
| Message | Textarea  | Yes      |
