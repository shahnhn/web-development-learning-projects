# Todo App

A simple and interactive Todo application built with HTML, CSS, and JavaScript. The application allows users to create, complete, delete, and filter tasks while storing their tasks in the browser using Local Storage.

## Features

* Add new tasks
* Add tasks using the Enter key
* Mark tasks as completed
* Delete individual tasks
* Filter tasks by:

  * All
  * Active
  * Completed
* Clear all completed tasks
* Display the number of remaining tasks
* Display the current date
* Save tasks using browser Local Storage
* Empty-state message when no tasks are available
* Responsive user interface

## Technologies Used

* **HTML5** – Application structure
* **CSS3** – Styling and responsive design
* **JavaScript** – Application functionality and DOM manipulation
* **Local Storage API** – Persistent task storage
* **Font Awesome** – Icons
